## Option 1: Open Source (AGPLv3 / LGPLv3 / MIT)

Free of charge. Use Kuberve in any project that complies with the license
terms. For AGPLv3 components (kernel, user, docs, spec), this means: if you
distribute a modified version or make it available over a network, you must
release the source code of your modifications under the same license.

This is ideal for:
- Personal use, learning, research.
- Internal tools that are not distributed to third parties.
- Open-source projects that are also AGPLv3-compatible.
- Applications that only use the userspace libraries (LGPLv3/MIT).

## Option 2: Commercial License

Paid. Required if you want to:
- Distribute a **closed-source** product based on Kuberve.
- Offer a **proprietary SaaS** that uses Kuberve code.
- Embed Kuberve in a hardware device without disclosing the source code of
  your modifications.
- White-label Kuberve as part of your product.

The commercial license removes the AGPLv3 copyleft obligations (you do not
have to open your source code) and grants you a non-exclusive, non-transferable
right to use, modify, and distribute Kuberve in proprietary products.
