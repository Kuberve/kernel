# Interrupt Vector Table (IVT) & Exception Handling — Kuberve

Этот модуль отвечает за низкоуровневую обработку прерываний и исключений в архитектуре **AArch64** (ARMv8-A). Он связывает аппаратные события процессора с логикой микроядра на языке Си.

## Архитектура таблицы векторов ARM64

В отличие от архитектуры x86, где таблица векторов состоит из голых адресов (указателей), в **AArch64** таблица содержит **векторы кода**. 
Таблица жестко разделена на **4 группы по 4 слота**. Каждый слот имеет фиксированный размер **128 байт (32 инструкции)**.

## Структура файлов модуля

* `vector_table.S` — Низкоуровневая ассемблерная таблица векторов прерываний. Должна быть аппаратно выровнена по границе **2048 байт**. Содержит макросы сохранения контекста.
* `interrupts.h` — Интерфейс подсистемы прерываний для ядра. Предоставляет inline-функции быстрого управления маской прерываний процессора (`enable_irq`, `disable_irq`).
* `interrupts.c` — Логика диспетчеризации прерываний и работы с контроллером **ARM GICv3** (Generic Interrupt Controller).

## Жизненный цикл обработки прерывания (IRQ)

1. **Аппаратный сигнал:** Внешнее устройство (например, таймер) генерирует сигнал прерывания.
2. **Ассемблерный перехват:** Процессор обращается к регистру `VBAR_EL1`, находит таблицу векторов и прыгает во вторую группу, слот `IRQ` (`exc_irq_el1`).
3. **Сохранение контекста (`kernel_entry`):** Макрос выделяет **256 байт** на стеке ядра и сохраняет регистры `x0–x30`.
4. **Прыжок в Си (`c_irq_handler`):**
   * Из системного регистра `ICC_IAR1_EL1` считывается уникальный `irq_id`.
   * По значению `irq_id` вызывается нужный драйвер (например, `irq_id == 30` — таймер ядра).
   * Сигнал об окончании обработки (`EOI`) отправляется обратно в регистр `ICC_EOIR1_EL1`.
5. **Восстановление контекста (`kernel_exit`):** Регистры восстанавливаются из стека.
6. **Возврат (`eret`):** Процессор восстанавливает состояние `PSTATE` из `SPSR_EL1` и прыгает по сохраненному адресу обратно к коду, который выполнялся до прерывания.

## Безопасность критических секций

Для предотвращения рассинхронизации структур данных микроядра при обработке разделяемых ресурсов прерывания можно временно блокировать:

```c
#include "ivt/interrupts.h"

// Блокируем прерывания и сохраняем старый статус
uint64_t flags = save_irq_disable();

/* --- Критическая секция ядра --- */

// Восстанавливаем прерывания в прежнее состояние
restore_irq(flags);
```
